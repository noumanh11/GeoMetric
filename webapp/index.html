Interactive map explorer

Choropleth countries use merged attributes from dashboard_data.js (same source as the Plotly dashboard). Toggle layers for airports, sampled flows, and temperature stations. Base maps: OpenStreetMap and Carto Dark (both use OSM data).

Pan and zoom. Use the layer control (top-right) to switch basemaps and overlay airports, flows, or stations. Country polygons: Natural Earth 110m via GitHub (network required once).
