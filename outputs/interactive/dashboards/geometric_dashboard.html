🗺 Projection Comparison
What each projection preserves and distorts
Key principle: Every projection of the spherical Earth onto a flat surface introduces distortion. The choice of projection is a scientific decision, not a cosmetic one — it changes the reader's perception of area, shape, distance, and direction.
Albers Equal-Area
✅ Preserves area · ⚠ Distorts shape at edges

Preserves: Area — all regions shown at true relative size


Distorts: Shape and angles, especially at map edges


Best for: Thematic choropleth maps, regional area comparison


Used in: Parts 2, 6 of this project

Lambert Conformal Conic
✅ Preserves shape · ⚠ Distorts area (poles inflated)

Preserves: Local shape (conformality) — angles correct locally


Distorts: Area — Greenland appears as large as Africa


Best for: Navigation, aeronautical charts, weather maps


Used in: Part 1 of this project

Winkel Tripel
✅ Balanced compromise · neither fully preserved

Preserves: Balanced — minimises overall distortion


Distorts: Neither area nor shape perfectly


Best for: General educational world maps (used by NGS since 1998)


Used in: Parts 3, 4, 6 of this project

ℹ About GeoMetric
Project Overview

GeoMetric is a full-stack geospatial analytics project demonstrating end-to-end data engineering and cartographic design skills.


7 Map Types: Choropleth, Proportional Symbols, Flow Map, Contour/Isopleth, Cartogram, Projections, Bivariate


Bonus Features: Interactive Dash dashboard, animated temporal choropleth, Moran's I spatial autocorrelation, NetworkX centrality


Tech Stack: Python · GeoPandas · Matplotlib · Folium · Plotly · Dash · NetworkX · PySAL · SciPy
